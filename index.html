Tracker · First-time Setup
Connect to Supabase so your data syncs across every browser and device.
Takes ~5 minutes. supabase.com is free.
1
Go to supabase.com → New project → choose any name & region
2
In the left sidebar → SQL Editor → paste and run this query:

create table entries (
  id bigint generated always as identity primary key,
  date text, week text, r numeric, trades int,
  wins int, losses int, phase text,
  created_at timestamptz default now()
);
3
Project Settings → API → copy Project URL and anon public key below
